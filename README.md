# Gopi Panikela — Video Editor Portfolio

Personal portfolio website for Gopi Panikela.

## Edit the portfolio

The main project data is inside `app.js` at the top in the `projects` array.

For each project you can change:
- title
- category
- description
- role
- tags
- thumbnail
- video
- external project link

## Add videos

For a simple GitHub Pages site, it is better not to store large MP4 files in the repository. You can host videos on YouTube/Vimeo/another video host and paste the embed URL into `video` in `app.js`.

For local testing, a relative file can also be used, for example:
`assets/videos/sindhuri.mp4`

## Publish

This is a plain static HTML/CSS/JS site and is designed for GitHub Pages.
